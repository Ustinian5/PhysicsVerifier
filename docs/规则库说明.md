# 规则库说明

当前三库来自 `combined_language_only.json` 的同一批2000道建库题。Qwen3-30B 完整回答1996道，GPT-OSS-120B medium 首次核查判出756份有错。沿用题族和来源隔离后，三组共用其中729份11月7日的核查原件。完整材料位于结果根的 `shared_experience/n2000/materials/`，四个种子的12个规模档见同级目录。[材料发布与原件核验](../scripts/release_shared_experience.py) · [各档产量](项目进展.md#独立建库规模)

| 材料 | 全库产量 | 与首次核查的关系 |
|---|---:|---|
| 经验 RAG | 729篇 | 每份保留原题、完整30B原答及首次核查的原始错误记录。 |
| 平铺 skills | 1452条 | 逐篇从上述案例提炼，727个来源有产出，另2次提炼失败。 |
| 规则树 | 883叶 | 655个来源贡献入树规则。每个叶的来源题号、首次核查错误编号见该档的 `sources.json`。 |

读取前用 `python -m scripts.release_shared_experience verify --root <结果根>` 在项目 conda 核验发布哈希。新选材和固定474题的效果待测。[读取入口](../rule_framework/shared_experience.py) · [实验口径](效果测评.md)

## 历史产物

11月21日的474题和已完成的步骤级100题使用739篇独立复核的 RAG、1471条 skills 和895个规则叶，成绩分别绑定当时的材料哈希。该版共享 PREPARE，三个知识组由 BM25 选材，每组最多6份全文、8192个材料 token。同源2000题的915叶是剔除前的中间树。旧v5的1467叶、混入 TextbookReasoning 的5000题扩容库，以及 Git 中供分段 verifier 使用的1123叶均属于其他发布。复现时按对应实验的输入、代码和材料哈希取用。已知同题族来源的处置和文字筛查的范围见[项目进展](项目进展.md)。
