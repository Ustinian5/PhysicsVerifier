# 规则库说明

本轮知识材料来自 `combined_language_only.json` 中独立划分的2000道建库题。目标30B有1996份完整回答，4份截断留档。120B从错误经验生成材料。发布时按题族筛查和来源裁决同步剔除案例、skills和规则叶，实际产物在结果根的 `aligned_old99/evaluation_revision`。题目级使用同一批材料的文件哈希。[材料构建](../scripts/run_aligned_organization.py) · [发布与剔除](../scripts/run_aligned_step_revision.py)

| 材料 | 当前发布 | 在线检索 |
|---|---:|---|
| 经验 RAG | 739份 | 每份含原题、30B原回答和120B独立核查说明，按扁平BM25排序 |
| 平铺 skills | 1471条 | 从案例提炼独立检查方法，按扁平BM25排序 |
| 规则树 | 895叶 | 每层按子节点名称及摘要的BM25取至多两个正分节点，再对可达叶排序 |

同一题的四组共用查询准备。三个知识组每组最多投递6份完整材料，材料预算8192 token。纯组继续同一会话，不接入知识库。结构和来源验收可复核，逐条物理正确性仍以具体证据判断。[检索实现](../rule_framework/flat_skill_rag.py) · [评测口径](效果测评.md)

## 历史产物

同源2000题的915叶是剔除前的中间树。旧v5的1467叶、混入 TextbookReasoning 的5000题扩容库，以及 Git 中供分段 verifier 使用的1123叶均属于其他发布。复现时按对应实验的输入、代码和材料哈希取用。已知同题族来源的处置和文字筛查的范围见[项目进展](项目进展.md)。
