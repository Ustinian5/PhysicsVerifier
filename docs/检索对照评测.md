## 运行

所有 Python 命令均在 conda 环境运行，例如 `conda activate physicsverifier`；依赖见根目录 `environment.yml`。`.env` 只在操作者本地配置：`OPENAI_BASE_URL`、`OPENAI_API_KEY` 用于组内 Terra API；`QWEN_BASE_URL`、`QWEN_API_KEY` 用于已验收的 Qwen 服务。历史 `ASTRA_*` 变量会覆盖通用 API 变量，运行 Terra 前应清除旧覆盖。模型服务返回的身份必须与请求完全一致。

1. **固定输入。** 若已有本次冻结输入，直接沿用并核对 SHA，不重新抽样。原始数据、GT、结果及私人日志不进入 PR，协作者通过授权的数据交接获取。准备新批次时：

   ```bash
   python scripts/prepare_retrieval_comparison.py \
     --source data/error_eval_dataset_100.cleaned.json \
     --audit data/historical_audit.json --pilot-cases data/development_cases \
     --output results/comparison/frozen50
   ```

   `--pilot-cases` 为原六例开发材料 C01–C06（含 `case_id/original_row`）；`--audit` 为历史审计的 `summary/details` JSON。脚本固定抽 50 条、种子 20260918，输出不含答案／GT 的 `inputs.json` 和操作端 `operator_only/reference_review.json`。本次输入 SHA 为 `aa94b53b0d1a5bb419fd5a8ab4e59d58b241de454adcd06005ab4342f62ea482`。

2. **采集检索。** 先用开发题验证接口，再运行冻结批次。下列单组示例用 `--arms 2 3 4` 可运行三组 API；本次已完成的 Terra 结果不得重跑。

   ```bash
   python scripts/run_retrieval_comparison.py \
     --input results/comparison/frozen50/inputs.json \
     --selection-manifest results/comparison/frozen50/manifest.json \
     --catalog catalogs/rules_unified_3000.json --phase retrieval_batch \
     --api-model gpt-5.6-terra --reasoning-effort medium --arms 1 \
     --output results/comparison/qwen
   ```

   只补技术失败，使用 `--retry-transient-from`、`--continue-pending`、`--replay-prefix`；异机原始路径用 `--relocate-root OLD NEW` 映射。并发、累计预算、退避和停止参数见 `--help`。不重跑成功或真实空选，不接受模型身份别名，不挑最好结果。

3. **统一 checker。** `--retrieval-run` 按父批次→续跑顺序显式列出全部关联目录，再列 Qwen 批次；不能只给最新子目录。先加 `--prepare-only` 检查输入和门槛（0 次 API），验收后移除此参数执行。仅有三组时显式 `--arms 2 3 4`，不能声称四组完成。

   ```bash
   python scripts/run_retrieval_checker.py \
     --input results/comparison/frozen50/inputs.json \
     --catalog catalogs/rules_unified_3000.json \
     --retrieval-run results/comparison/terra results/comparison/qwen \
     --arms 1 2 3 4 --output results/comparison/checker --prepare-only
   ```

   checker 只读原题、候选解答和规则，不读检索理由、参考答案或 GT。完整 HTTP 请求相同才复用首次响应；中断记录须核对后再续，不能删除失败当作未执行。

4. **独立复核并计分。** 真实 checker 运行生成 `manifest.json` 后导出诊断复核表：

   ```bash
   python scripts/score_retrieval_comparison.py prepare \
     --input results/comparison/frozen50/inputs.json \
     --reference-review results/comparison/frozen50/operator_only/reference_review.json \
     --checker-run results/comparison/checker --arms 1 2 3 4 \
     --output results/comparison/diagnosis_review.json
   ```

   复核表在操作端显示组别，不称为盲审。填写真实 `reviewer`；逐题核验旧主张，删除误标／重复根因、补充真实漏标，将独立物理错误填入 `adjudicated_errors`（`error_id/error_text`），填写 `reference_review_notes` 后置 `reference_review_complete=true`。每条诊断填写物理依据 `rationale`；只在诊断理由成立且对应真实错误时填 `matched_error_ids`，错误诊断填空列表，完成后置 `review_complete=true`。不得用模型自评冒充人工金标。新发现的 GT 统一用于所有组。

   ```bash
   python scripts/score_retrieval_comparison.py score \
     --input results/comparison/frozen50/inputs.json \
     --reference-review results/comparison/frozen50/operator_only/reference_review.json \
     --checker-run results/comparison/checker --arms 1 2 3 4 \
     --review results/comparison/diagnosis_review.json \
     --output results/comparison/metrics.json
   ```

   输出逐组错误级 micro TP/FP/FN、precision、recall、F1 及有效检出题数。最大一对一匹配防止同一错误被多次算 TP，多余诊断计 FP；任何缺题、失败或未复核均拒绝输出整批物理分数，分母为零写 null。评分会核对冻结输入、checker manifest 和全部诊断原文。诊断表和指标默认拒绝覆盖。

`evaluate_physics_eval_sets.py` 仍可提供历史引文／位置匹配辅助指标，但位置重叠不能代替物理正确性判定。当前样本来自历史错答池，不据此报告正确答案误报率。规则命中率需要另外复核规则适用性，不等于诊断 precision。

## Terra 直接检查与自主规则检查

同一模型在连续会话中完成诊断，规则工具可自主使用，没有下游Qwen。以下命令仅用于新结果目录，已有成功结果或真实空诊断不重跑：

```bash
conda activate physicsverifier
python scripts/run_llm_checker_baseline.py \
  --api-mode responses --model gpt-5.6-terra --reasoning-effort medium \
  --input results/retrieval_comparison_50_20260920/frozen50/inputs.json \
  --selection-manifest results/retrieval_comparison_50_20260920/frozen50/manifest.json \
  --out_json results/new_direct/results.json --env-file .env
```

纯模型不加规则参数；树组加 `--rule-catalog catalogs/rules_unified_3000.json --rule-access tree`，叶组改为 `--rule-access leaves`。各组使用独立目录。`--drain-transient`仅补技术故障；`--allow-backup`是显式授权的备用额度开关，仅主额度低于停止线才切换，不用于绕过限流。Responses批次固定50题与既有规则哈希，不能直接用于新数据集或下一轮新协议。

`evaluate_direct_baseline_comparison.py --experiment-root results/retrieval_comparison_50_20260920 --verify-reference-only`会离线复现旧四组共同49题分数，不写新指标。不加该开关计算纯Terra；`--tree-review`和`--leaf-review`分别计算新增组，结果写回对应组的唯一指标文件。计分依赖该根目录下的冻结输入、旧四组指标及checker记录、盲审准备包和Terra原始证据；须通过授权数据交接获得，不能只传最终分数。保留历史目录关系及原始证据绝对路径；当前直接计分入口不支持自动迁移绝对路径。模型输入不包含GT，操作端计分才读取参考材料。

独立物理复核入口仍用上节的 `score_retrieval_comparison.py`（原四组），自动代理计分不能替代复核。
