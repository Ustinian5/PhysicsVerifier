# 效果测评

当前先验收目标30B回答的步骤级检查。题目级评测和规模曲线暂缓；状态见[项目进展](项目进展.md)。

## 输入与独立标注

题面来自原始物理题源，先隔离建库与评测；30B重新作答。Sol high独立进行四轮步骤标注，仅可见题设、完整新回答、原参考答案及指定前序标注；不看规则库或verifier输出。旧4B标签和评分不能迁移。

120B仅可见题设、新30B回答及对应辅助知识。小样本先比较纯模型与原题源规则树；正式扩展再增加同源原始经验RAG和平铺skills。检索和检查保持连续上下文，公共提示与预算一致，不拆独立checker。

## 步骤级口径

沿用历史一对一原文位置匹配（IoU≥0.5或覆盖率≥0.6），不改阈值追求涨分。本轮显式修复字符偏移0被当成缺失的边界错误；历史评分默认行为及保存结果不变。

- Precision：匹配诊断数/可定位诊断数；同时报告以全部发布诊断为分母的结果。
- Recall：匹配参考错误数/已确认参考错误数；没有引文的遗漏错误保留在分母，另报可定位参考口径。
- F1：上述Precision与Recall的调和平均；分母为0明确标记。
- 未决参考不强判正负；接口、格式及定位失败与正常空诊断分开。每表报告实际题数、诊断数、参考错误数和失败数。

位置重叠只能说明定位吻合，不能证明两条诊断指向相同物理错误。小样本逐条核对原始诊断、参考理由和匹配记录，展示命中、漏检及误报实例；机器/助手复核均human_gold=false。

## 验收边界

先验收6题生成、24项Sol标注及两组12项检查，再放量。验收检查身份、无标签泄漏、原文定位和计分正确性，不要求某组得分更高。未决或缺题设内容保留，不能以模型判无错自动认定全推理正确。

历史开发题面不称独立论文测试集；离线检查分数也不能替代30B训练收益。历史输出、标签和成绩保持原样。代码入口为[生成](../scripts/run_qwen30b_step_verifier.py)、[检查](../scripts/run_qwen30b_step_checks.py)、[独立标注](../scripts/run_bench_reannotation.py)及[位置匹配](../scripts/evaluate_physics_eval_sets.py)。
