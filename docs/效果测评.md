# 效果测评

当前评测只从 `data/combined_language_only.json` 取题和原参考。建库、步骤级和题目级的待检回答均来自 `Qwen3-30B-A3B-Instruct-2507` 的冻结生成记录。验收按题干、原始请求、响应模型身份和实际回答正文核对；题号、目录名或模型别名不足以确定身份。各组检查时只看原题、完整30B回答和本组获准的材料。数据规模、进度和分数见[项目进展](项目进展.md)。

## 步骤级

100道题由 GPT-6.1 Sol high 对照原参考进行四轮标注，随后冻结助手对引文、根因和自我纠错的裁决。180个确认错误中，16个在原回答中已明确纠正，主指标计算其余164个；另有2个未决。引文定位到该题同一份30B回答的字符区间。命中还须有同一根因、同一方向的复核记录，每组每题的一条诊断和一个根因各最多计一次。[标注入口](../scripts/run_corrected_annotations.py) · [发布与计分](../scripts/review_aligned_step_revision.py)

主指标的 Precision 为命中数除以可定位诊断数，Recall 为命中数除以164，F1 为二者的调和平均数。逐组另报全部发布数、不可定位数、内容失败和使用全部发布诊断作分母的结果。该批采用离线计分，新增语义评分 API 调用为0。[验收入口](../scripts/audit_aligned_step_revision.py)

## 最终答案

新版从702个保留候选核查题设、参考及30B最终回答。GPT-OSS-120B medium 在独立会话中看原参考复核标签，分歧由助手绑定原文裁决，记录 `human_gold=false`。原目标为正误各300。11月21日裁决结束后合格正确367道、错误237道，按用户授权取最大平衡集，从原候选顺序保留最先的237道正确和全部237道错误，共474道。预测端可见题干、30B解答和本组获准的材料。四组共用一次查询准备，三个知识组由程序检索、投递全文，同一会话最终输出正确、错误或未决。[题级协议](../rule_framework/final_answer_revision.py) · [题量修订与逐题绑定](../scripts/final_answer_cohort.py)

所有题目级评测统一以 **30B 的最终答案错误** 为正类。逐题对照该批冻结标签与 verifier 判定，标错判错计 TP，标对判错计 FP，标错判对计 FN，标对判对计 TN。旧工具版600题、新版474题及按题数抽取的子集均使用以下唯一一组指标。

| 指标 | 公式 | 含义 |
|---|---|---|
| Precision | TP / (TP + FP) | verifier 判错的回答中，标注为错的比例 |
| Recall | TP / (TP + FN) | 标注为错且获有效二分类判定的回答中，verifier 判错的比例 |
| F1 | 2TP / (2TP + FP + FN) | Precision 与 Recall 的调和平均 |

每组只将明确判对或判错的题计入混淆矩阵，公式分母为零时取 0。各组另列有效判定数 / 总题数、弃权数、内容失败数。需要衡量全题覆盖时，单列“全体标错题检出率”，即 TP / 该批全部标错题数。旧审计和新版计分 JSON 的正式三项均取 `groups.<组别>.original_binary_view`。[计分实现](../scripts/audit_final_answer_metrics.py)

## 评测题数与结论稳定性

正式474题计分后，复用同一批四组输出。在正确、错误两类内分别按种子 `20261121` 与题号的 SHA-256 排序，各取前50、100、200、237题，组成100、200、400、474题四个嵌套子集。每档四组使用相同题目，报告原口径 P/R/F1、有效覆盖、弃权和内容失败。474题的四组统计须与正式发布逐项一致。

每个知识组比较相对纯120B的 F1 差值（百分点）。在每档固定子集内按正误分层、有放回地配对重抽10000次，给出差值的95%百分位区间。另从完整题集中按相同正误比例、不放回地抽取1000套嵌套子集，统计各档高于、持平和低于纯组的次数。最后一档包含全部样本，只有一个选题结果。

在项目 conda 环境运行 `python -m scripts.analyze_final_answer_sample_size --root <final_revision_balanced>`。程序核对题集和1896份逐组判定后，在同一目录写入 `sample_size_stability.json`，新增模型请求为0。[离线分析代码](../scripts/analyze_final_answer_sample_size.py)
