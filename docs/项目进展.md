# 项目进展

更新：2026-11-07。

目标：验证基于错题经验构建的verifier能否更准确地检查Qwen3-30B回答，并作为reward用于30B训练。

## 当前路线

原始物理题库先按题族划分建库、开发和测试。30B生成回答；GPT-OSS-120B负责核查建库回答、提炼经验和知识组织。测试时同样由120B在连续上下文中完成检索与检查，不拆独立checker，不调用embedding模型。

| 对照组 | 提供给120B的辅助材料 |
|---|---|
| 纯120B | 无 |
| RAG | 原题、30B回答和120B核查说明 |
| skills | 从同批经验提炼的平铺检查方法，无树结构 |
| 规则树 | 从同批经验提炼的物理规则及层级索引 |

bench必须使用目标30B的回答，包含正确和错误解答。按题目级Precision、Recall、F1计分，不匹配错误位置；同时报告正确题误报率、技术失败和真实案例。扩大bench题数，用同一批输出计算预先固定子集的规模曲线。离线检查评测完成后，再进行30B训练reward对照，训练收益单独验证。
