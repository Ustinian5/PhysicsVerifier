# 规则目录说明

- `rules_unified_3000.json`：当前 development 基线，1123 条规则、189 个 Scenario Cluster；2026-07-30 至 31 的 20+20 validation 使用该文件。
- `rules_unified_3000_runtime_backfilled.json`：4875 条规则、488 个 Scenario Cluster 的历史运行时参考库；完整配置消融已否决，不是当前默认方案。
- `rules_unified.json`：514 条规则的基线库。
- `rules_catalog_top_down.json`、`rules_300_tagged.json`、`semantic_experience_distilled_300.json`：规则库构建输入。
- `scenario_cluster_blueprints.json`：Scenario Cluster 配置源。
- `legacy/`：历史结构、中间产物和旧实验版本，不用于当前主流程。

命令行入口没有隐式的 unified catalog 默认值。运行实验时必须显式指定 catalog，并记录路径与 SHA-256。未发布的 1139 增量候选和 1123+metadata 受控消融产物只保存在 `results/`，均不得当作正式库使用。

规则库结构、规模和维护方式见 [`docs/规则库说明.md`](../docs/规则库说明.md)。
效果测评的 catalog 口径、数据隔离和结果见 [`docs/效果测评.md`](../docs/效果测评.md)。
